Get Started

Install from PyPI and start in seconds.

autoskill

AI that teaches itself to use any software.

pip install autoskill
autoskill run "check stock on supplier.com"
autoskill skills

code-explore

Build a searchable knowledge base of all your projects.

pip install code-explore
cex scan ~/Projects
cex search "REST API auth"

code-adapt

Track upstream changes and adapt them for your project.

pip install code-adapt
cadp init
cadp observe upstream-repo
